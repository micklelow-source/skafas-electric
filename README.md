# Skafas Electric website

Static one-page site for Skafas Electric (Hampstead, NH). No build step: just `index.html`.

## Before going live
Replace the bracketed placeholders in `index.html`: `[PHONE]`, `[EMAIL]`, `[NH LICENSE]`, `[MA LICENSE]`, `[XX]`, the photo placeholders, the logo box, and `[FORM_ID]` (create a free form at formspree.io so the contact form emails you).

## Hosting on GitHub Pages
Settings → Pages → Source: "Deploy from a branch" → Branch: `main`, folder `/ (root)` → Save.
The site will be live at `https://<your-username>.github.io/skafas-electric/`.
